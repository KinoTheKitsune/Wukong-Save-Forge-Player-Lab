## 📖 Overview

Wukong Save Alchemist is a **Black Myth companion suite** built for players who want to fine-tune their personal experience without disrupting the artistic intent of the original game. Think of it as a tuning fork for your own save file — a quiet instrument that lets you adjust the resonance of your journey through the Fated One's tale.

Instead of scrambling through memory editors or opaque tools, Wukong Save Alchemist offers a **transparent, well-documented workspace** where every change is previewed, versioned, and reversible. Whether you want to soften a brutal boss wall, explore the world at your own pace, or just experiment with unusual builds that base progression never quite supports, this companion gives you the levers — and the receipts for every pull.

The project started in 2024 as a small note-taking tool for tracking skill points across multiple characters and slowly evolved into a full **Stat and Player Editor companion** with a companion-first design philosophy: your save is sacred, and every operation is journaled.

---

## ✨ Why Wukong Save Alchemist?

Most editing tools treat your save file like a black box: feed it a number, hope for the best. We took the opposite approach. Wukong Save Alchemist treats your save like a **hand-bound manuscript** — every page turned, every margin note added, is recorded so you can always trace back to the original.

- 🧭 **Companion-first philosophy** — no surprises, only deliberate choices
- 🛡️ **Reversible by design** — automatic snapshotting before every write
- 🌍 **Multilingual interface** — 12 languages at launch, more coming
- ⚡ **Responsive UI** — usable on a Steam Deck screen or a 4K monitor
- 🕐 **24/7 support** — real humans, not scripted replies
- 🎨 **Themeable workspace** — dark, light, and high-contrast modes

## 🎯 Feature List

### 🧬 Player & Stat Editing
- Fine-grained adjustment of health, stamina, mana, and focus pools
- Attribute redistribution with instant preview
- Damage scaling sliders for players who prefer a more measured pace
- God-like defensive toggle for exploration sessions (off by default)
- Infinite resource mode described internally as **boundless endurance** for uninterrupted experimentation

### 🏔️ Progression Tools
- Skill tree reallocation without losing unlocked nodes
- Chapter and shrine bookmarking for fast re-entry
- Currency and material editor with soft caps to keep the experience grounded
- Quest state inspection with plain-language explanations
- Boss defeat ledger for tracking personal challenge runs

### 🗂️ Save Management
- Multi-slot profile manager with custom labels
- Automatic timestamped backups before every write operation
- Snapshot comparison view — see exactly what changed
- Portable profile export and import
- Integrity checker to catch corrupted saves before they bite

### 🖥️ User Experience
- Responsive UI that scales from small handhelds to ultrawide
- Multilingual support: EN, IT, DE, FR, ES, PT-BR, PL, RU, JA, KO, ZH-Hans, ZH-Hant
- Keyboard and controller friendly navigation
- Inline help tooltips that explain every field in plain language
- Fully offline — the app never phones home

### 🔐 Safety & Trust
- No network requirement at runtime
- No telemetry, no analytics, no tracking pixels
- Every operation logged locally in a human-readable journal
- Rollback button on every screen
- Community-driven changelog with full transparency
